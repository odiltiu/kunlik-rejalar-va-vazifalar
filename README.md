# 📋 Kunlik Rejalar — React Task Planner

React yordamida yaratilgan kunlik vazifalarni rejalashtirish va boshqarish ilovasi (Task Planner).

## 🚀 Texnologiyalar

- **React 19**
- **Vite**
- **Zamonaviy CSS Dizayn**

## 🌟 Imkoniyatlar

- Yangi vazifa qo'shish
- Vazifani tahrirlash (Edit)
- Bajarilgan deb belgilash (Toggle Done)
- Vazifani o'chirish (Delete)
- Jami vazifalar hisoblagichi

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build
npm run build
```
